Gateway Sensor Studio

Select sensors, map pins, and auto-build your gateway JSON.

Choose up to five industrial sensors, set their pins, and assign each to a unique microcontroller. The first microcontroller becomes the master automatically.

Build Rules

Max 5 sensors One sensor per MCU Auto master MCU Pin mapping required

Select sensors from the dropdown, enter pins, then assign each to a microcontroller. The JSON preview updates once every MCU has one sensor.
